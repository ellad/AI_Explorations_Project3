About the project

About Cloud Closet

Cloud Closet turns a live weather forecast into clothing guidance for a day away from home.

How recommendations work

The final recommendation method and temperature bands will be added as the forecast and recommendation systems are implemented.

Privacy and data

Manual city and ZIP searches use location files stored with this app. Device location is requested only after you choose Use my location. After a location is selected, its representative coordinates are sent to Open-Meteo for a fresh forecast. Cloud Closet stores only your latest selected location on this device; search text, weather responses, and device-location history are not saved.

Sources and credits

Created by Ella Gault. Forecast data is provided by Open-Meteo. Location data comes from the US Census Bureau.

Character, clothing, accessory, weather, and reminder artwork was generated with ChatGPT under Ella Gault’s direction. Ella edited selected pieces and reviewed the complete SVG set for the final application. No third-party artwork is used.

Cloud Closet is a forecast-based prototype, not an emergency-alert service.
